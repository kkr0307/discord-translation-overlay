# 🌍 Discord Translation Overlay (디스코드 번역 오버레이)

> 🤖 **Vibe Coding Project:** 이 프로젝트의 코드는 기획부터 개발, 오류 수정, 배포 세팅까지 **거의 100% AI 에이전트와의 페어 프로그래밍(바이브 코딩)**을 통해 작성되었습니다.

디스코드나 PC 게임 등에서 외국어(일본어, 영어 등)로 소통할 때, **마우스 드래그 한 번으로 즉시 번역 결과를 화면에 띄워주는** 가볍고 빠른 번역 프로그램입니다. 

## 🚀 주요 기능 (Features)

### 1. 드래그 앤 드롭 오버레이 번역
채팅이나 웹페이지의 텍스트를 마우스로 드래그해보세요! 화면이나 게임을 가리지 않고 마우스 커서 위치에 바로 투명한 번역창이 팝업됩니다. 내용만 확인하고 나면 창은 알아서 서서히 사라집니다.

### 2. 실시간 양방향 번역창 (Live Translator)
작업 표시줄 우측 하단의 트레이 아이콘을 우클릭하여 '실시간 번역창 열기'를 눌러보세요. 파파고(Papago)처럼 직관적인 번역창이 열립니다. 
> 💡 **강력한 AI 번역:** 
> 단순한 기계 번역이 아닙니다. 원문의 존댓말/반말 뉘앙스를 그대로 살리고, 인터넷 신조어(`ㅎㅇ`, `ㅋㅋ` 등)까지 센스 있게 번역해 줍니다!

### 3. 자동 업데이트 기능
새로운 버전이 출시되면 프로그램을 켤 때 알아서 최신 버전을 감지하여 팝업을 띄워줍니다. '예'를 누르면 클릭 한 번에 다운로드부터 덮어쓰기 설치까지 전부 자동으로 진행됩니다. 귀찮게 사이트를 다시 방문할 필요가 없습니다!

## 📦 설치 및 실행 방법 (Installation & Usage)

1. **다운로드:** GitHub의 [Releases] 페이지에서 최신 버전의 `DiscordTranslator_Installer.exe`를 다운로드 받아 설치합니다.
2. **최초 실행 및 API 키 입력:** 
   프로그램은 무료이지만 Google Gemini AI를 사용하기 위해 무료 API 키가 필요합니다.
   - [Google AI Studio](https://aistudio.google.com/)에 접속하여 구글 로그인 후 **'Get API key'**를 눌러 새로운 키를 생성합니다.
   - 프로그램을 켜면 나오는 설정창에 복사한 API 키를 붙여넣기하고 저장합니다.
3. **언어 설정:**
   설정창에서 번역할 언어(도착 언어)와 탐지할 언어(출발 언어)를 선택합니다.
4. **사용 시작!**
   이제 윈도우 상의 어떤 텍스트든 드래그하면 번역 오버레이가 나타납니다.

## ❓ 자주 묻는 질문 (FAQ)

- **Q. 프로그램이 보이지 않아요!**
  A. 이 프로그램은 백그라운드에서 동작하므로 작업 표시줄 우측 하단(시스템 트레이)에 숨어 있습니다. `번역기 모양 아이콘`을 찾아서 우클릭해보세요.
- **Q. 번역이 안 뜹니다.**
  A. API 키가 정확히 입력되었는지 확인해 주세요. 무료 키라도 결제 등록이 되어있지 않으면 초과 사용 시 일시적으로 멈출 수 있습니다.
- **Q. 게임 안에서는 어떻게 쓰나요?**
  A. 게임이 창 모드(또는 전체 창 모드)일 때 게임 내 채팅 텍스트를 마우스로 드래그할 수 있는 상태라면 바로 적용됩니다!
